PDF to Summary

Document processing workspace

  • Go
  • Redis
  • React
  • Vite
  • Docker Compose
View project details

A workspace for reading a PDF alongside an editable summary and checking the result against the original page.

A Go worker extracts pages locally with Poppler or uses Gemini for scanned documents. Redis tracks each job, and the browser receives live processing updates over WebSocket.

Inside the project
Reading forms
Text coordinates keep field labels and values together. Rotated margin notes open separately.
Summary history
Regenerate in another language, edit a saved version or export it as Markdown.
Retention reports
See which documents expire next. Saving a newly generated summary starts a fresh seven-day window.
